# 📈 Simulador de Circuito RLC

Simulador interativo de circuito RLC série para ensino de fenômenos de ressonância.

## ✨ Funcionalidades

- ⚡ Visualização em tempo real da corrente alternada
- 📊 Osciloscópio integrado
- 📈 Curva de ressonância
- 📐 Diagrama fasorial
- 🎮 Controles interativos

## 🚀 Como executar

```bash
pip install -r requirements.txt
python circuito_rlc.py
